# 隐私政策（免费娱乐版）

最后更新：2026-07-22

本应用为**免费娱乐扑克**（仅虚拟筹码，不涉及真实货币、充值或兑付）。
以下说明我们收集哪些数据、如何使用，以及你如何管理自己的数据。

## 1. 我们收集的数据
- **账号信息**：用户名、显示名、密码哈希（PBKDF2，不存储明文密码）。
- **游戏数据**：筹码余额、胜率/利润、手牌数、ELO 段位、头像地址。
- **对局与账本**：出牌记录、虚拟筹码流水（用于对账与反作弊）。
- **技术日志**：登录 IP、设备/连接元数据、审计日志（用于安全与防作弊）。

## 2. 数据用途
- 提供对局、匹配、排行榜与社交功能；
- 反作弊、风控与安全防护（含登录失败锁定）；
- 运营分析与产品改进。

## 3. 我们不做什么
- 不出售你的个人数据；
- 不接入真实货币支付；
- 不在未告知的情况下共享个人身份信息给第三方。

## 4. 你的权利（删除与导出）
- **删除账号**：登录后调用 `POST /api/account/delete`（需持有效 token）。
  服务端会匿名化你的个人身份信息（用户名改为 `deleted_<id>`、清空显示名/密码哈希/头像），
  并清除你的虚拟筹码流水。
- **数据导出 / 其他请求**：请联系运营方（见第 6 节）。

> 说明：免费娱乐版无真实资金审计留存义务，故删除时直接清除筹码流水；
> 若未来引入合规留存需求，将改为打标保留而非物理删除，并另行告知。

## 5. 安全措施
- 密码使用 PBKDF2 加盐哈希存储；
- 登录接口按账户维度限流，连续失败达到阈值后临时锁定账户；
- 管理员接口需独立 token，未配置时拒绝以生产模式启动。

## 6. 联系我们
如对个人数据有任何疑问或请求，请通过应用内反馈或运营方公示渠道联系。

> 本文件为占位模板，正式上线前应由法务根据目标市场（如 GDPR / 个人信息保护法）审阅并补全。
